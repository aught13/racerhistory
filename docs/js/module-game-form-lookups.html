Module: game-form-lookups

Game Form Lookups - AJAX search with dynamic results tables and popover forms Replaces static select dropdowns with type-ahead search inputs and small results tables. Each lookup manages: - Debounced search queries to AJAX endpoints - A compact results table showing entity fields - A hidden input for the selected entity ID - Visual feedback for the current selection
