Module: modules/tinymce-bootstrap-config

TinyMCE Bootstrap Configuration Module Provides a centralized, reusable TinyMCE configuration optimized for Bootstrap 5 styling and responsive content creation. Features: - Bootstrap-compatible content styling - Responsive image handling with float options - Full table editing support - Custom image upload handler - Dark/Light mode aware editing - Proper block formats for semantic HTML
