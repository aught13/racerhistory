TeamSeasonAdminService

Encapsulates complete admin orchestration for TeamSeasons, including list, detail composition (games, rosters, prev/next links, stats), add/edit form preparation, persistence, and bulk deletion.

Notes:

  • Preserve result array keys expected by TeamSeasonsController templates.
  • Keep image-resolution fallback silent (missing image is non-fatal).
  • Reuse this service for future TeamSeason admin endpoints before adding controller-side query logic.
