SeasonAdminService

Encapsulates the complete admin orchestration for season management so the controller only handles request validation, Flash messaging, and redirects. This service owns list/detail queries, create/update/delete, and popup-form save behavior.

Notes:

  • Keep season navigation logic (previous/next season) here.
  • Preserve compact return contracts because controller tests assert behavior.
  • Avoid introducing HTTP-layer dependencies inside service methods.
