StatsService

Generic statistics service that coordinates sport-specific stat services. Acts as a facade/coordinator for sport-specific statistics operations, delegating to the appropriate sport service based on sport ID/name.

This service eliminates the need for controllers to know about specific sport implementations (e.g., BasketballStatsService). Controllers only interact with this generic service, which routes to the correct sport service.
